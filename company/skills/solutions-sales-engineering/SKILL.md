# Solutions & Sales Engineering Protocol

1. **Technical Discovery & Feasibility:**
   - Map customer requirements against platform capabilities, constraints, and latency budgets.
   - Run technical feasibility audits before commercial commitments are finalized.
   - Clarify edge cases and technical boundary assumptions early.

2. **Proof-of-Concept (POC) Design:**
   - Craft high-impact, lightweight POC architectures demonstrating core value props.
   - Ensure POC code adheres to production-grade memory safety and architectural standards.

3. **Competitive Differentiation:**
   - Use live web search (`web_search`, `web_fetch`) to research industry benchmarks and competitive offerings.
   - Articulate specific technical advantages (sub-millisecond latency, zero memory leaks, local sovereignty).
